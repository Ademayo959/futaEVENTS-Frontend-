# futaEVENTS — Frontend 🎉

The frontend for futaEVENTS — a platform where FUTA students 
discover and share events happening on campus.

No more missing out because you didn't see the WhatsApp flyer in time.

## What it does

- Browse all events happening across FUTA campus
- Post your own event in seconds
- Get the organizer's contact and registration link directly from the listing
- Clean, minimal UI built for students on the go

## Built With

- React + Vite
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
git clone https://github.com/yourname/futaevents-frontend
cd futaevents-frontend
npm install
npm run dev
```
